# 4.2 Wing Dimensions

## Overview

This document summarizes the dimensional parameters associated with the aircraft wing.

The wing is the primary lifting surface and represents one of the most important geometric components within the aircraft model.

---

## Documented Parameters

The wing configuration includes:

* Span
* Root Chord
* Tip Chord
* Taper Ratio
* Sweep Angle
* Dihedral Angle
* Wing Area
