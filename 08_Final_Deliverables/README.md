# Final Deliverables

## Overview

This section contains the primary outputs generated during the completion of the project.

The deliverables provided within this repository represent the final aircraft model and associated project assets.

These files allow the aircraft geometry to be reviewed, modified, and reused within OpenVSP.

The OpenVSP model serves as the primary technical output of the project.

The model contains:

- Main Wing
- Horizontal Tail
- Vertical Tail
- Propeller

assembled into a complete aircraft configuration.
