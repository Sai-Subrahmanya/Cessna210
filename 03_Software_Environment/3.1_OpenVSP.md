# 3.1 OpenVSP

## Overview

OpenVSP (Open Vehicle Sketch Pad) is an open-source parametric geometry modeling software developed by NASA.

The software is widely used in aerospace engineering for conceptual aircraft design, geometry generation, and vehicle configuration studies.

Unlike traditional CAD software, OpenVSP focuses specifically on aerospace vehicle development and provides tools designed for aircraft geometry creation.

---

## Why OpenVSP?

OpenVSP was selected because it provides:

* Parametric geometry creation
* Aircraft-specific design tools
* Rapid geometry modification
* Aerospace-focused workflows
* Open-source accessibility

These capabilities make it particularly suitable for aircraft geometry modeling projects.

---

## Role Within This Project

OpenVSP was used to:

* Create the fuselage geometry
* Create the wing geometry
* Create the horizontal tail
* Create the vertical tail
* Create the propeller
* Assemble the complete aircraft model

The final deliverable included in this repository is an OpenVSP project file containing the completed aircraft geometry.
