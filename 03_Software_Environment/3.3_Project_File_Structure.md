# 3.3 Project File Structure

## Overview

The final project consists of documentation, dimensional analysis records, geometry images, and the completed OpenVSP model.

Each category serves a different purpose within the repository.

---

## Documentation

Documentation files explain:

* Aircraft information
* Modeling methodology
* Dimensional analysis
* Model architecture
* Project outcomes

---

## Images

Images are used to document:

* Aircraft dimensions
* Geometry parameters
* Final aircraft views
