# 4.3 Horizontal Tail Dimensions

## Overview

This document summarizes the dimensions associated with the horizontal stabilizer.

The horizontal tail contributes to aircraft longitudinal stability and trim control.

---

## Documented Parameters

Typical parameters include:

* Span
* Root Chord
* Tip Chord
* Taper Ratio
* Sweep
* Area
