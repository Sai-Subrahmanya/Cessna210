# 8.1 OpenVSP Model

## Overview

The OpenVSP project file represents the final aircraft model developed during this project.

The model contains all major aircraft components integrated into a single aircraft configuration.

---

## Included Components

The model contains:

- Fuselage
- Main Wing
- Horizontal Tail
- Vertical Tail
- Propeller

---

## Software Requirement

The file should be opened using OpenVSP.

---

## Usage

The model may be used for:

- Geometry inspection
- Educational purposes
- Aircraft visualization
- Parametric modification
- Further analysis workflows
