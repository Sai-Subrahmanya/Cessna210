# 2.3 Aircraft Specifications

## Overview

This document summarizes the primary characteristics of the aircraft represented by the final OpenVSP model.

Values presented here are intended to provide general context and should be considered approximate reference values.

---

## Aircraft Configuration

| Parameter          | Value                        |
| ------------------ | ---------------------------- |
| Aircraft Type      | Fixed-Wing Aircraft          |
| Propulsion         | Single Propeller             |
| Wing Configuration | High Wing                    |
| Tail Configuration | Conventional Tail            |
| Modeling Method    | Parametric Geometry Modeling |

---

## Major Components

The aircraft consists of:

* Fuselage
* Main Wing
* Horizontal Tail
* Vertical Tail
* Propeller
