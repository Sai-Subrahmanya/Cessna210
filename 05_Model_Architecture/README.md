# Model Architecture

## Overview

This section documents the structure of the completed aircraft model.

The final OpenVSP model consists of five primary aircraft components assembled into a complete aircraft configuration.

Rather than documenting the development process, this section focuses on the final architecture of the aircraft model.

---

## Included Components

### 5.1 Fuselage

Main structural body of the aircraft.

### 5.2 Wing

Primary lifting surface.

### 5.3 Horizontal Tail

Provides longitudinal stability and trim.

### 5.4 Vertical Tail

Provides directional stability.

### 5.5 Propeller

Provides thrust and propulsion.
