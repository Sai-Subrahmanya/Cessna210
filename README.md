# NASA Variant Cessna 210 Aircraft Modeling Using OpenVSP

## Overview

This repository contains a complete parametric recreation of the NASA Variant Cessna 210 aircraft developed using OpenVSP (Open Vehicle Sketch Pad).

The project focuses on aircraft geometry modeling, dimensional analysis, and parametric aircraft design. The final model was developed from reference drawings and dimensional data and assembled into a complete aircraft configuration consisting of the fuselage, main wing, horizontal tail, vertical tail, and propeller.

This repository has been organized as a project archive containing the final model, dimensional analysis, engineering documentation, and supporting project files.
