# Aircraft Dimensional Analysis

## Overview

This section documents the primary dimensions and geometric parameters used within the completed aircraft model.

The purpose of this section is to provide a centralized location for the dimensional information associated with each major aircraft component.

The dimensions presented here represent the final values used within the OpenVSP model.

---

## Included Components

The following aircraft components are documented:

### 4.1 Fuselage Dimensions

Overall fuselage geometry and dimensional information.

### 4.2 Wing Dimensions

Wing parameters including span, chord lengths, sweep, taper ratio, and dihedral.

### 4.3 Horizontal Tail Dimensions

Horizontal stabilizer dimensions and configuration.

### 4.4 Vertical Tail Dimensions

Vertical stabilizer dimensions and configuration.

### 4.5 Propeller Dimensions

Propeller geometry and related parameters.
