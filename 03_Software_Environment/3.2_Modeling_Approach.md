# 3.2 Modeling Approach

## Overview

The aircraft model was developed using a parametric geometry modeling approach.

Rather than manually drawing aircraft surfaces, geometry was created using dimensional parameters and aircraft-specific design features available within OpenVSP.

---

## Parametric Modeling

Parametric modeling defines geometry using numerical values rather than static drawings.

Examples include:

* Wingspan
* Chord Length
* Sweep Angle
* Dihedral Angle
* Fuselage Length

Modifying these parameters automatically updates the aircraft geometry.

---

## Development Strategy

The model was developed using the following high-level workflow:

1. Collect reference material.
2. Review aircraft dimensions.
3. Define geometry parameters.
4. Create aircraft components.
5. Assemble the aircraft model.
6. Validate geometry against references.

---

## Benefits

This approach provides:

* Consistent geometry
* Rapid modification
* Improved organization
* Better reproducibility
