# 6.5 Model Summary

## Overview

The completed model represents a parametric recreation of the NASA Variant Cessna 210 aircraft using OpenVSP.

The final aircraft geometry integrates all major aircraft components into a complete and coherent aircraft configuration.

---

## Included Components

- Fuselage
- Main Wing
- Horizontal Tail
- Vertical Tail
- Propeller
